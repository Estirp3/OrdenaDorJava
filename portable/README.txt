# OrdenaDor - Version Portable

## Como usar:

1. Ejecuta OrdenaDor.bat
2. La aplicacion se abrira automaticamente

## Requisitos:

- Java 17 o superior instalado
- Si no tienes Java, descargalo desde: https://adoptium.net/

## Contenido:

- OrdenaDor.bat: Ejecutable principal
- lib/OrdenaDor.jar: Aplicacion
- icon.png: Icono de la aplicacion

## Funcionalidades:

- Organizador de archivos por categorias
- Limpiador del sistema
- Limpiador de cache de navegadores
- Detector de archivos duplicados
- Analizador de espacio en disco
